# Independent chart layers — approved design and implementation plan

Plot-only changes. Seven selectors plotted_range_zone (including yellow), plotted_stretch_zones, plotted_fast_ma, plotted_slow_ma, plotted_bollingers, plotted_candlesticks, plotted_ichimoku_cloud accept 1h/4h, default4h. candlestick_type regular default or heikin_ashi. Different layers may coexist on one timestamp axis. Existing trades/positions/PnL and Lux/trade glyphs/colors/toggles remain. Trading remains 4h. HA transforms only displayed OHLC, calculated recursively through prehistory before clipping; every indicator/zone/cloud uses regular OHLC. Use the same MA/ATR/Bollinger periods/types and zone formulas separately on each native timeframe. Indicators/zones become available on completed_at. No forming bars. Reversal markers retain existing timeframe setting.

Ichimoku conversion9/base26/long52, leading spanA=(conversion+base)/2 and spanB=52-high/low midpoint, both displaced26 native candles forward. Green ifA>B/lightred ifA<B. Values use only data completed at calculation, including source prehistory for left-edge cloud. Future cloud uses calendar-derived native slots, no future price request. Hide indicators/cloud/zones with existing indicators=false; shade_ranging_area controls regular range shading, yellow enable flag still respected. Defaults produce only 4h layers.

Approach: new chart_data.py pure transforms and bounded chart-only data preparation; new chart_renderer.py datetime-axis layers/markers. Modern plot runs request prepared chart_data from run_simulation after trade loop; ordinary /run keeps existing computation and adds plotting metadata only. Legacy result/otherstrategy rendering stays fallback. Reuse actual loaded4h frames. Fetch1h through native get_bars with bounded >=one-year prehistory (expand bound for configured long periods), no cross-reference search needed for chart-only use. Serialize finite data, date strings; never send pandas frames to JSON. Chart-only settings validated separately from StrategySettings. No product strategy changes or additional dependencies.
